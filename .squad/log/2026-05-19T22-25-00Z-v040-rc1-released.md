## Release Summary

**Milestone:** rc17 — BLE-link lifecycle, finish-screen precision, glasses battery → phone (optional). MARKETING_VERSION bumped to 0.4.0.

### Four Major Fixes

1. **Link lifecycle contract formalized (Richards ADR):** BLE link is user-managed, not workout-scoped. Disconnect only on user action or system error recovery. Codifies "pairs like AirPods" mental model.
2. **Workout-stop bug fixed (Laughlin):** Finish frame no longer dropped on stop. `teardownTransport()` removed from all workout-stop paths per ADR rule R1. Link persists for user to read finish screen.
3. **Finish-screen Y anchors recomputed (Laughlin):** Migrated from obsolete `y_fb = 206 − T` formula to canonical rc16 `y_fb = 255 − wearer_top`. Results: symmetric layout, fully on-panel, pinned by new tests.
4. **Auto-reconnect backoff + battery filter (Weiss):** Unbounded reconnect attempts at 1/2/4/8/16/32/60 s schedule. Battery characteristic (0x2A19) subscribed per-link, not per-workout. `BatteryLevelFilter` drops >100 bytes (firmware glitches), suppresses dupes, resets on disconnect.
