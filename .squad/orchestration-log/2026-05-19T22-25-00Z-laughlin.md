## Work Done

1. **Workout-stop lifecycle fix (root cause of rc16 regression):**
   - **Bug #1:** `pushHUDSummaryIfConnected()` ran AFTER `controller.end()`, racing HK for foreground runtime. Finish frame was dropped.
   - **Bug #2:** Immediate `teardownTransport()` severed the link, breaking the user mental model ("why do I need to re-pair?").
   - **Bug #3:** Same teardown on cancel path conflated "discard run" with "unpair hardware."
   - **Fix:** Stop per-tick HUD task first (prevent live HUD race-overwrites) → push finish frame while HK still alive → end HK session → **do NOT call `teardownTransport()`**. Deleted the private helper to make re-introduction impossible.
2. **Finish-screen Y anchors (precision fix under rc16 formula):**
   - Old constants (`timeY/distanceY/paceY` = 166/86/6) were derived under obsolete `y_fb = 206 − T` formula.
   - Old `paceY=6` was rendering the *distance* field, not pace (name lied).
   - Recomputed under canonical rc16 formula `y_fb = 255 − wearer_top`:
     - `finishBannerY = 239` (wearer-top 16)
     - `finishTimeY = 159` (wearer-top 96)
     - `finishDistanceY = 79` (wearer-top 176)
   - Result: even 16-px gaps, 16-px margins, 3 lines of font 3 (h=64), symmetric, fully on-panel.
   - Old constants deprecated with compiler nudges (`@available(*, deprecated, renamed:)`).
   - **Tests pinned:** `test_finishScreenYCoords_followLensFlipFormula_rc17` asserts formula AND on-panel invariant; `test_summaryFrames_yAnchorsUseFinishScreenConstants_rc17` decodes wire bytes and asserts per-frame y-anchor matches constant.
3. **Glasses battery → iPhone (WatchConnectivity):**
   - `WCMessage` gains `glassesBattery(level: Int)` case (schema v3, backward-compatible with v2).
   - `WorkoutMirrorPublisher` protocol adds `sendGlassesBattery(_:)`.
   - `WatchConnectivityService.sendGlassesBattery` routes through existing three-tier `transmit(..., preferQueued: true)` (queued, survives transient disconnect, latest-only fits 30 s cadence).
   - Phone-optional: silent no-op if session unactivated or unreachable.
   - **iPhone side:** `WorkoutMirrorViewModel.glassesBatteryLevel: Int?`, `GlassesBatteryIcon` (SF Symbol + tint: red ≤15%, orange ≤30%, green otherwise), rendered in `WorkoutMirrorView` above metrics grid.
   - **No new permissions, no new state machine.**
