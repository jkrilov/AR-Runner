## Spawn Context

**Failure Diagnosis:** ARRunnerWatch build target failed on macOS-latest + Xcode 16 CI runner. Root cause: watchOS 11 SDK is shipped with `xcode-select` but simulator runtime is not pre-installed.

**Why:** iOS and other simulator runtimes are bundled in the Xcode package. watchOS simulator runtime requires an explicit `xcodebuild -downloadPlatform watchOS` step that App-launched schemes trigger (destination resolution) but non-app schemes (widget extension) skip.

**Solution:** Conditional download step gated on matrix cell (`contains(matrix.destination, 'watchOS')`). Only cells targeting watchOS run the download; iOS builds skip it entirely, preserving CI speed.
