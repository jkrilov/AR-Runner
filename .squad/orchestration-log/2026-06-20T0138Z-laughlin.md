### 2. Variable HUD Grid Support

**Core model (ARRunnerCore, Codable + Hashable):**
- New `HUDGridConfig: Sendable, Codable, Equatable, Hashable`
  - `lines: [Int]` (count 2–4, each element 1 or 2)
  - `static let standard = [2,1,1]`
- `HUDLayout.grid: HUDGridConfig?` optional + additive
  - Missing field in JSON → `nil` (synthesized Codable)
  - `nil` → standard4 legacy behavior (byte-identical to v0.6.4)
  - **No WCMessage schema bump** (field rides inside `HUDLayout` Codable, lenient decode tolerates additive field)
- Validation: `2 ≤ lines.count ≤ 4`, `lines.allSatisfy { $0 == 1 || $0 == 2 }`, `lines.reduce(0,+) == slots.count` (invalid → fall back to standard4)

**Geometry factory (ARRunnerCore, code-only):**
- `HUDGridDefinition.make(for: HUDGridConfig) -> [Slot]`
  - Early-returns literal `standard4` for `[2,1,1]` (hand-tuned from bench, not formula-clean)
  - General factory for other shapes using Weiss's coordinate/font tables
  - All non-`[2,1,1]` coords marked `// TODO(bench)` for Engo 2 calibration
- Watch uses `layout.grid ?? .standard` (defaults to legacy standard4 if nil)

**Rendering (RunningHUDFrame, unchanged renderer):**
- `RunningHUDFrame.frames(metricStrings:layout:grid:)` resolves `layout.grid ?? .standard`, feeds `HUDGridDefinition.make(for:)`
- Slot renderer otherwise unchanged; all new behavior in factory
- Width-warning generalized to every 2-item right slot (not hard-coded index 1)
