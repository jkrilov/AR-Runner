## Key Design Decisions

1. **Linux spike: GREEN.** `ARRunnerCore` imports only `Foundation` + `XCTest`. No Apple-framework code. Compiles cleanly on `swift:6.0-jammy` container.
2. **Runner split enforces architecture:** Linux core-tests job mechanically prevents HealthKit / CoreBluetooth / WatchKit / WCSession / UIKit / AppKit leakage into ARRunnerCore. This is an enforcement of ADR-001 + ADR-007.
3. **Concurrency groups save macOS minutes:** Rapid PR pushes cancel in-flight runs; main pushes are never cancelled. Different policies for different audiences.
4. **Caching tuned per runner:** Linux uses SPM cache; macOS uses SPM + DerivedData. Cache misses are tolerated (optimization, not correctness).
5. **CodeQL on single scheme:** CodeQL runs only on `ARRunnerWatch` (largest dependency closure). Marginal coverage gain doesn't justify full matrix cost.
