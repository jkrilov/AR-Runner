### Adaptive Font Sizing Rule
| lineCount | 1-item line | 2-item line |
|-----------|-------------|-------------|
| 2         | font 4 (75) | font 3 (64) |
| 3         | font 3 (64) | font 2 (38) |
| 4         | font 2 (38) | font 2 (38) |

Fewer lines & fewer items → taller font. Heights from ALookFontMetrics (F1=24, F2=38, F3=64, F4=75, F5=82).

### Data Model (Backward-Compatible)
```swift
public struct HUDGridConfig: Sendable, Codable, Equatable, Hashable {
    public let lines: [Int]  // count 2–4, each element 1 or 2
}
public struct HUDLayout: ... {
    public let grid: HUDGridConfig?  // nil ⇒ legacy [2,1,1] standard4
}
```
- Legacy decode: `grid` missing → `nil` → standard4 mapping (byte-identical to v0.6.4)
- Forward-compat: additive JSON field; pre-0.6.5 decoders ignore extra key
- **No WCMessage schema bump** (grid rides inside `HUDLayout` Codable; lenient decode tolerates it per additive-within-v6 design)

### Risk Register & Bench-Validation Plan
**HIGH:** 2-line big-font geometry unbenched → gate Phase 2 behind on-glass bench pass  
**MEDIUM:** 2-item collisions on new fonts; heading `°` glyph width unverified  
**LOW:** legacy decode (covered by optional field), preview over-promising (muted treatment)

**Validation per new lineCount × per-line items combo:**
1. Blank screen / off-panel clip (text anchored past x_fb<0 or y_fb band off-panel)
2. Vertical overlap (adjacent lines too close, especially 4-line 26px gaps and 2-item drop-font centring)
3. Horizontal clipping (long values overflow right edge, worst on 2-item right and wide font-4/5 1-item lines)

**Phasing:**
- **Phase 1 (v0.6.5):** ship 4-line (all font 2) + 3-line, lowest bench burden
- **Phase 2 (v0.6.x, bench-gated):** 2-line big-font (font 4, then optional font 5)
- **Phase 3 (polish):** true horizontal centering for 1-item lines
