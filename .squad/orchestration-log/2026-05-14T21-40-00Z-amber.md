## Spawn Context

- **Issue:** 3 of 5 build checks failed post-Richards: `ARRunnerWatch`, `ARRunnerWidgetsWatch`, `ARRunnerWidgetsPhone` (down from 1 failure pre-fix).
- **Root Cause Investigation:** Two distinct error symptoms, one underlying cause.
  - watchOS cells: `xcodebuild -downloadPlatform watchOS` exit 70 (Apple ID auth required on GitHub-hosted runners).
  - iOS widget cell: destination resolver failure — `iOS 18.0 is not installed` on macos-15 under pinned Xcode 16.0.
- **Key Finding:** `Ineligible destinations: { name:Any iOS Device }` is NOT evidence of destination-spec error; it's xcodebuild's enumeration fallback when no simulator runtimes are installed for the platform.

## Decision

Pin Xcode 16.4 via `maxim-lobanov/setup-xcode@v1`; remove `xcodebuild -downloadPlatform` step entirely. Xcode 16.4 ships pre-baked iOS 18.5 + watchOS 11.5 simulator runtimes on macos-15 image (both ≥ D2 minimums).

## Outcome

✅ All 5 checks green. Commit 38580ce merged. No regressions.

## Lessons Logged

1. `-downloadPlatform` does not work unattended; needs Apple ID auth.
2. Xcode symlink paths (e.g., `/Applications/Xcode_16.app`) are brittle across image rotations.
3. Cross-check runner-image manifest for both installed SDKs AND simulator runtimes.
4. `Ineligible destinations:` is enumeration, not diagnosis.
